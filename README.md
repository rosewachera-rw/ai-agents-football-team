# AWS Agentic Football Cup EMEA ECT Hackathon

AI Agent Football Team participated in the AWS EMEA ECT Hackathon as part of the AWS Agentic Football Cup. This is a flow of the code, prompts and AWS services used to *build the AI agents*.

Toolset used to build *production* agentic systems today. Some of the tools used:
- *Amazon Bedrock*: Foundational models that power the agents reasoning
- *Bedrock AgentCore*: A managed runtime to deploy, scale and monitor your agents
- *Claude Sonnet 4.6*: LLM used by the AI agents
- *Strands Agents SDK*: An open-source framework for building agents with minimal boilerplate
- *Kiro*: An agentic IDE that understands your project and helps you build, debug, and iterate on agents through natural conversation

The purpose of utilizing these tools is to have hands-on experience building agentic solutions that can be applied to any domain including cybersecurity.
